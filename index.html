                        Мои биржи

                        Отметьте биржи фриланса, которыми пользуетесь — дашборд будет показывать заказы, сообщения и оплаты из их писем в Gmail. Если не пользуетесь ни одной, оставьте всё пустым — раздел «Биржи» скроется.

                        Аккаунт Google и почта

                        Как получить файл ключа (один раз, ~5 минут)
                        1. Откройте console.cloud.google.com под своим Google-аккаунтом и создайте проект, например «Мой дашборд».
                        2. Включите Gmail API: страница Gmail API → «Включить».
                        3. Настройте экран согласия: Google Auth Platform → «Начать». Название — любое, тип — Внешний (External), почта — ваша.
                        4. В разделе Аудитория добавьте свою почту в тестовые пользователи.
                        5. В разделе Клиенты → «Создать клиента» → тип Приложение для ПК → «Создать» → Скачать JSON.
                        6. Вернитесь сюда, нажмите «Выбрать файл ключа» и укажите скачанный файл. Затем «Войти через Google».

                        Дашборд получает доступ только на чтение писем. Ключ и вход хранятся у вас на компьютере.

                        ☁️ Резервная копия в Google

                        Все записи (задачи, финансы, расходы шоу, заметки…) сами копируются в скрытую папку вашего Google Диска — через несколько секунд после каждого изменения (значок ☁️ вверху показывает, что всё сохранено). Если программа удалится или сломается компьютер: установите дашборд, войдите через тот же Google — и нажмите «Восстановить».
